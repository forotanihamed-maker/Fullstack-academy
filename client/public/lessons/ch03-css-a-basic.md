## بخش A: CSS مقدماتی

### ۳.۱ CSS چیست؟ `[ضروری]`

**مفهوم.** CSS (Cascading Style Sheets) زبانی است که ظاهر و چیدمان المان‌های HTML را تعیین می‌کند. HTML می‌گوید «این یک عنوان است»؛ CSS می‌گوید «آبی، بزرگ و وسط‌چین باشد.»

**ساختار یک قاعده (Rule):**

```css
h1 {
  color: #1d4ed8;
  font-size: 2rem;
}
```

```
h1 { color: #1d4ed8; }
|      |        |
|      |        value
|      property
selector

       \_____________/
          declaration
```

- **Selector:** کدام المان‌ها را انتخاب کن.
- **Declaration:** هر جفت `property: value;`.
- **Declaration Block:** همه‌ی declarationها بین `{ }`.

**سه روش اضافه کردن CSS:**

```html
<!-- ۱) Inline: مستقیم روی المان (اولویت بالا، نگهداری سخت: پرهیز کن) -->
<p style="color: red;">متن</p>

<!-- ۲) Internal: داخل style در head (مناسب نمونه‌ی کوچک) -->
<style>
  p { color: red; }
</style>

<!-- ۳) External: فایل جدا (روش اصلی پروژه‌ها) -->
<link rel="stylesheet" href="css/style.css" />
```

| روش | مزیت | عیب |
|-----|------|-----|
| Inline | سریع برای تست | Specificity بالا، شلوغی HTML، بازاستفاده ندارد |
| Internal | یک فایل | فقط برای همان صفحه |
| External | بازاستفاده، کش مرورگر، تفکیک وظایف | یک درخواست اضافه |

**کامنت در CSS:** `/* توضیح */` فقط همین شکل؛ `//` در CSS کامنت نیست.

**اشتباهات رایج**

- فراموش کردن `;` بین declarationها (declaration بعدی ممکن است نادیده گرفته شود).
- اشتباه در مسیر فایل CSS. اگر استایل اعمال نشد، اول تب Network و Console را نگاه کن.
- خطای املایی در property خطا نمی‌دهد، فقط آن خط نادیده گرفته می‌شود. در DevTools خط خط‌خورده می‌بینی.

**تمرین کوچک:** `style.css` را به صفحه‌ی ساده‌ات لینک کن، رنگ `h1` را عوض کن و بعد یک اشتباه املایی عمدی در property بنویس و در DevTools ببین چه می‌شود.

### ۳.۲ Selectorها `[ضروری]`

#### Selectorهای پایه

```css
p { line-height: 1.8; }                 /* المان */
.card { padding: 16px; }                /* کلاس (با نقطه) */
#pricing { margin-top: 40px; }          /* شناسه (با #) */
* { box-sizing: border-box; }           /* همه‌ی المان‌ها */
h1, h2, h3 { font-weight: 700; }        /* گروه‌بندی: یک قانون برای چند selector */
p.note { color: #92400e; }              /* ترکیب: المان p که کلاس note دارد (بدون فاصله) */
```

#### Selectorهای ترکیبی (Combinators)

```css
nav li { display: inline-block; }       /* نسل‌ها: li داخل nav (در هر عمقی) */
ul > li { list-style: none; }           /* فرزند مستقیم */
h2 + p { font-size: 1.1rem; }           /* هم‌سطح بعدیِ بلافاصله */
h2 ~ p { color: #475569; }              /* همه‌ی هم‌سطح‌های بعدی */
```

| Combinator | نماد | معنی |
|------------|------|------|
| Descendant | فاصله | هر نسلی داخل |
| Child | `>` | فرزند مستقیم |
| Adjacent sibling | `+` | برادر بلافاصله بعدی |
| General sibling | `~` | همه‌ی برادرهای بعدی |

#### Attribute Selector

```css
a[target="_blank"] { color: #7c3aed; }
input[type="email"] { direction: ltr; }
a[href^="https"] { }      /* با https شروع شود */
a[href$=".pdf"] { }       /* با .pdf تمام شود */
a[href*="example"] { }    /* شامل example باشد */
```

#### Pseudo-class (وضعیت المان، با یک `:`)

```css
a:hover { text-decoration: underline; }                  /* ماوس روی آن */
button:focus-visible { outline: 3px solid #2563eb; }     /* فوکوس با کیبورد */
input:checked + label { font-weight: 700; }              /* checkbox انتخاب‌شده */
li:first-child { font-weight: 700; }
li:last-child { border: 0; }
li:nth-child(2n) { background: #f1f5f9; }                /* زوج‌ها */
li:not(.active) { opacity: .7; }
input:invalid { border-color: #dc2626; }
```

#### Pseudo-element (بخشی از المان، با دو `::`)

```css
p::first-line { font-weight: 700; }
input::placeholder { color: #94a3b8; }
::selection { background: #fde68a; }

.badge::before {
  content: "جدید";     /* بدون content کار نمی‌کند */
  background: #dc2626;
  color: #fff;
  padding: 2px 6px;
  border-radius: 4px;
}
```

**فرق Pseudo-class و Pseudo-element:**

| | Pseudo-class | Pseudo-element |
|---|--------------|----------------|
| نماد | `:` | `::` |
| یعنی | المان در وضعیت خاص | بخشی از المان یا بخش ساختگی |
| مثال | `:hover`، `:first-child` | `::before`، `::after`، `::placeholder` |

> **نکته:** محتوای تولیدشده با `::before` و `::after` در DOM وجود ندارد. محتوای مهم (که باید خوانده یا انتخاب شود) را در آن‌ها نگذار.

**اشتباهات رایج**

- فراموش کردن `.` برای class یا `#` برای id.
- یکی گرفتن `ul li` (همه‌ی نسل‌ها) با `ul > li`.
- استفاده از id برای استایل‌دهی (Specificity بالا؛ در بخش پیشرفته می‌بینی).
- نوشتن `::before` بدون `content`.
- Selectorهای خیلی طولانی مثل `div.container ul li a span`؛ شکننده‌اند.

**تمرین کوچک:** در یک لیست ۶تایی، ردیف‌های زوج را رنگ دیگری بده، اولین آیتم را ضخیم کن و بعد از متن آخرین آیتم یک ✓ (با `::after`) اضافه کن.

### ۳.۳ رنگ‌ها `[ضروری]`

```css
.demo {
  color: tomato;                     /* نام رنگ */
  color: #1d4ed8;                    /* Hex ۶ رقمی */
  color: #1d4ed8cc;                  /* Hex با شفافیت (۸ رقمی) */
  color: rgb(29, 78, 216);           /* RGB */
  color: rgb(29 78 216 / 0.8);       /* RGB مدرن با شفافیت */
  color: hsl(224, 76%, 48%);         /* Hue, Saturation, Lightness */
  background-color: transparent;
}
```

| فرمت | چه زمانی؟ |
|------|-----------|
| Hex | رایج‌ترین؛ از طراحی (Figma) کپی می‌شود |
| `rgb()` | وقتی شفافیت یا محاسبه لازم است |
| `hsl()` | وقتی می‌خواهی تیره‌تر یا روشن‌تر کنی (فقط Lightness را عوض کن). برای ساخت پالت عالی است |

**کنتراست:** متن باید روی پس‌زمینه کنتراست کافی داشته باشد (راهنمای WCAG: حداقل ۴.۵ به ۱ برای متن معمولی). خاکستری کم‌رنگ روی سفید خیلی رایج و خیلی بد است. DevTools مقدار کنتراست را نشان می‌دهد.

**اشتباهات رایج:** انتخاب رنگ فقط بر اساس سلیقه بدون سنجش کنتراست؛ استفاده از رنگ تنها برای انتقال معنا (مثلاً خطا فقط قرمز).

**تمرین کوچک:** یک رنگ اصلی را با `hsl` بنویس و سه سایه‌ی روشن‌تر و تیره‌تر از آن بساز (فقط عدد Lightness را عوض کن).

### ۳.۴ واحدها `[ضروری]`

| واحد | نسبت به | مثال و کاربرد |
|------|---------|----------------|
| `px` | پیکسل ثابت | جزئیات کوچک، سایه، border |
| `%` | والد | `width: 50%` |
| `rem` | اندازه‌ی فونت ریشه (`html`، معمولاً ۱۶px) | فونت و فاصله‌ها (مقیاس‌پذیر با تنظیمات کاربر) |
| `em` | اندازه‌ی فونت همین المان (برای `font-size`: والد) | فاصله‌هایی که باید با فونت همان المان مقیاس شوند (مثل `padding` دکمه) |
| `vw` / `vh` | ۱٪ عرض / ارتفاع viewport | بخش تمام‌صفحه |
| `ch` | عرض کاراکتر `0` | محدود کردن عرض خط متن (`max-width: 65ch`) |

```css
html { font-size: 100%; }            /* همان ۱۶px، اما با احترام به تنظیم کاربر */
h1 { font-size: 2.5rem; }            /* ۴۰px */
p { max-width: 65ch; }               /* خط خوانا */
.hero { min-height: 100vh; }
button { padding: .75em 1.5em; }     /* با اندازه‌ی فونت دکمه مقیاس می‌شود */
```

**قاعده‌ی عملی:**

- **فونت:** `rem` (نه `px`، تا کاربری که فونت مرورگر را بزرگ کرده، اثرش را ببیند).
- **فاصله‌ها:** `rem` یا `em`.
- **جزئیات بسیار ریز** (خط ۱px، سایه): `px`.
- **عرض‌های انعطاف‌پذیر:** `%`، `fr`، `max-width`.

> **نکته‌ی موبایل:** `100vh` روی موبایل ممکن است با نوار مرورگر هماهنگ نباشد؛ واحدهای `dvh` و `svh` راه مدرن‌اند (پشتیبانی را در MDN بررسی کن).

**اشتباهات رایج**

- `em` تو در تو که اندازه‌ها را ناخواسته چند برابر می‌کند (مثلاً `em` روی لیستِ داخل لیست).
- `px` برای فونت‌های بدنه.
- `width: 100vw` که به خاطر اسکرول‌بار، افقی اسکرول می‌سازد (از `width: 100%` استفاده کن).

**تمرین کوچک:** `font-size: 100%` را روی `html` بگذار و همه‌ی اندازه‌های یک صفحه را به `rem` ببر. بعد در تنظیمات مرورگر اندازه‌ی فونت را بزرگ کن و ببین صفحه چطور پاسخ می‌دهد.

### ۳.۵ Box Model `[ضروری]`

هر المان یک جعبه است با چهار لایه، از داخل به بیرون:

```
+------------------------ margin ------------------------+
|  +--------------------- border ---------------------+  |
|  |  +------------------ padding -----------------+  |  |
|  |  |                                             |  |  |
|  |  |        content (width x height)             |  |  |
|  |  |                                             |  |  |
|  |  +---------------------------------------------+  |  |
|  +-----------------------------------------------------+  |
+------------------------------------------------------------+
```

| لایه | وظیفه |
|------|-------|
| `content` | خود محتوا (با `width` و `height`) |
| `padding` | فاصله‌ی داخلی، بین محتوا و border (پس‌زمینه را شامل می‌شود) |
| `border` | حاشیه |
| `margin` | فاصله‌ی بیرونی از المان‌های دیگر (شفاف) |

```css
.card {
  width: 300px;
  padding: 16px;                       /* هر ۴ طرف */
  border: 2px solid #cbd5e1;
  margin: 24px auto;                   /* ۲۴ بالا/پایین، چپ/راست خودکار (وسط‌چین) */
  border-radius: 12px;
}
```

**ترتیب Shorthand:**

```css
margin: 10px;                    /* همه */
margin: 10px 20px;               /* بالا و پایین | چپ و راست */
margin: 10px 20px 30px;          /* بالا | چپ و راست | پایین */
margin: 10px 20px 30px 40px;     /* بالا | راست | پایین | چپ (ساعت‌گرد) */
```

**`box-sizing`، مهم‌ترین تنظیم:** به‌طور پیش‌فرض (`content-box`) `width` فقط محتوا را تعیین می‌کند و `padding` و `border` اضافه می‌شوند. این یعنی `width: 300px` با `padding: 20px` و `border: 2px` در عمل ۳۴۴px جا می‌گیرد، که چیدمان را به‌هم می‌ریزد.

```css
/* مدرن و رایج: width شامل padding و border هم می‌شود */
*, *::before, *::after {
  box-sizing: border-box;
}
```

**Margin Collapse (ادغام margin):** margin عمودی دو بلوک مجاور ادغام می‌شود و بزرگ‌ترین مقدار اثر می‌کند (مثلاً ۳۰ و ۲۰ می‌شود ۳۰، نه ۵۰). این در Flex و Grid اتفاق نمی‌افتد.

**وسط‌چین افقی بلوک:** `margin: 0 auto` (یا `margin-inline: auto`) با `width` یا `max-width` مشخص.

**اشتباهات رایج**

- فراموش کردن `box-sizing: border-box`.
- اشتباه گرفتن `padding` و `margin` (پس‌زمینه در `padding` دیده می‌شود نه `margin`).
- `margin: auto` روی المان `inline` (فقط روی بلوک کار می‌کند).
- `height` ثابت برای متن (وقتی متن بیشتر شود سرریز می‌کند؛ بهتر است `min-height` بگذاری).

**تمرین کوچک:** دو `div` پشت هم بساز با `margin-bottom: 20px` و `margin-top: 30px`. فاصله‌ی واقعی بین آن‌ها را در DevTools (نمایش Box Model) بخوان.

> **RTL و ویژگی‌های منطقی (Logical Properties):** به‌جای `margin-left` و `margin-right` که به جهت فیزیکی وابسته‌اند، می‌توانی بنویسی `margin-inline-start` (ابتدای خط) و `margin-inline-end` (انتهای خط). در `dir="rtl"` ابتدا راست است. در بخش پیشرفته بیشتر می‌بینی.

### ۳.۶ Background `[ضروری]`

```css
.hero {
  background-color: #0f172a;
  background-image: url("../images/hero.jpg");
  background-size: cover;        /* کل کادر را پر کن (ممکن است برش بخورد) */
  background-position: center;
  background-repeat: no-repeat;
}

/* گرادیان (به‌عنوان تصویر) */
.banner {
  background: linear-gradient(135deg, #1d4ed8, #7c3aed);
}

/* چند پس‌زمینه */
.hero {
  background:
    linear-gradient(rgb(0 0 0 / .5), rgb(0 0 0 / .5)),
    url("../images/hero.jpg") center / cover no-repeat;
}
```

| خاصیت | مقادیر رایج |
|-------|--------------|
| `background-size` | `cover` (پر می‌کند و می‌برد)، `contain` (کامل نشان می‌دهد) |
| `background-position` | `center`، `top`، `20% 50%` |
| `background-repeat` | `no-repeat`، `repeat-x` |

**`background-image` یا `<img>`؟** تصویری که بخشی از محتوا است (عکس محصول، نمودار) باید `<img>` با `alt` باشد. تصویر تزئینی را با `background-image` در CSS بگذار (پس‌زمینه‌ی CSS به screen reader چیزی نمی‌گوید).

**نکته‌ی مرتبط:** برای کنترل اندازه‌ی `<img>` در کادر از `object-fit: cover` استفاده می‌شود (مثل `background-size: cover`)؛ این‌ها را در بخش متوسط ببین.

**اشتباه رایج:** گذاشتن متن مهم روی تصویر بدون پوشش تیره یا گرادیان؛ خوانایی خراب می‌شود.

### ۳.۷ فونت و متن `[ضروری]`

```css
body {
  font-family: "Vazirmatn", Tahoma, "Segoe UI", sans-serif;
  font-size: 1rem;
  font-weight: 400;
  line-height: 1.8;
  color: #1e293b;
}

h1 {
  font-size: 2.25rem;
  font-weight: 800;
  line-height: 1.3;
  text-align: center;
  letter-spacing: -0.01em;
}

a { text-decoration: none; }
.title { text-transform: uppercase; }
```

| خاصیت | توضیح |
|-------|-------|
| `font-family` | لیست اولویت (Font Stack)؛ آخرین مورد یک خانواده‌ی عمومی (`sans-serif`، `serif`، `monospace`) |
| `font-size` | اندازه (`rem`) |
| `font-weight` | ضخامت: `400` معمولی، `700` ضخیم |
| `line-height` | فاصله‌ی خطوط (مثلاً `1.8`، بدون واحد بنویس)؛ برای فارسی معمولاً ۱.۷ تا ۲ مناسب است |
| `text-align` | `start`، `end`، `center`، `justify`، و `left` و `right` (منطقی: `start` / `end`) |
| `text-decoration` | زیرخط (`none`، `underline`) |
| `text-transform` | تغییر حروف انگلیسی (`uppercase`، `capitalize`)؛ روی فارسی اثری ندارد |
| `letter-spacing` | فاصله‌ی حروف؛ در فارسی و عربی نباید بزرگ شود، چون حروف به هم متصل‌اند و اتصال شکسته می‌شود |

**استفاده از فونت وب (مثلاً Vazirmatn):** فونت باید در سیستم کاربر باشد یا خودت آن را بارگذاری کنی:

```css
@font-face {
  font-family: "Vazirmatn";
  src: url("../fonts/Vazirmatn-Regular.woff2") format("woff2");
  font-weight: 400;
  font-style: normal;
  font-display: swap;      /* ابتدا فونت جایگزین را نشان بده */
}

@font-face {
  font-family: "Vazirmatn";
  src: url("../fonts/Vazirmatn-Bold.woff2") format("woff2");
  font-weight: 700;
  font-display: swap;
}
```

- فایل فونت را در پروژه (پوشه‌ی `fonts/`) نگه می‌داری و با `@font-face` معرفی می‌کنی. فرمت `woff2` سبک‌تر و برای وب مناسب است.
- `font-display: swap` از «متن نامرئی» تا لود فونت جلوگیری می‌کند.
- می‌توانی فونت را از CDN هم بگیری؛ ولی فایل محلی کنترل و حریم خصوصی بهتری می‌دهد.

**اشتباهات رایج**

- `line-height` با واحد `px` (در اندازه‌های مختلف فونت به‌هم می‌خورد).
- استفاده از فونت بدون fallback.
- لود چند وزن فونت غیرضروری (هر وزن یک فایل است).
- `letter-spacing` مثبت روی متن فارسی.
- استفاده از `text-align: justify` روی متن‌های کوتاه یا ستون‌های باریک (فاصله‌های ناجور).

**تمرین کوچک:** یک متن فارسی بلند را با سه مقدار `line-height` (۱.۳ و ۱.۸ و ۲.۴) ببین و عدد مناسب را انتخاب کن؛ بعد `max-width: 65ch` بده و ببین خوانایی چقدر بهتر می‌شود.

### ۳.۸ display `[ضروری]`

`display` نوع جعبه‌ی المان را تعیین می‌کند.

| مقدار | رفتار |
|-------|-------|
| `block` | خط جدید؛ کل عرض، `width` و `height` و `margin` کامل کار می‌کنند |
| `inline` | در ادامه‌ی متن؛ `width` و `height` و `margin` عمودی اثر ندارد |
| `inline-block` | در ادامه‌ی خط، ولی `width` / `height` و `padding` / `margin` کامل کار می‌کنند |
| `none` | المان کاملاً حذف می‌شود (جا نمی‌گیرد و برای screen reader هم نیست) |
| `flex` / `grid` | چیدمان مدرن (بخش بعد) |

```css
nav a { display: inline-block; padding: 8px 12px; }
.hidden { display: none; }
```

**روش‌های مخفی کردن؛ تفاوت‌ها:**

| روش | جا می‌گیرد؟ | دیده می‌شود؟ | screen reader؟ |
|-----|-------------|---------------|-----------------|
| `display: none` | خیر | خیر | خیر |
| `visibility: hidden` | بله | خیر | خیر |
| `opacity: 0` | بله | شفاف (ولی هنوز قابل‌کلیک و فوکوس) | بله |

**اشتباهات رایج**

- دادن `width` به المان `inline` (`span`، `a`) و تعجب از بی‌اثر بودنش.
- استفاده از `opacity: 0` به‌عنوان «مخفی» (المان هنوز فوکوس می‌گیرد).
- `inline-block` و فاصله‌ی ناخواسته‌ی بین المان‌ها (به‌خاطر فاصله‌ی HTML)؛ با `display: flex` حل می‌شود.

### تمرین‌های CSS مقدماتی

**ساده**

1. در صفحه‌ی HTML فصل قبل، فونت، رنگ متن و `line-height` را تنظیم کن.
2. به همه‌ی المان‌ها `box-sizing: border-box` بده و با DevTools تفاوت را نشان بده.
3. لینک‌ها را بدون زیرخط کن و با `:hover` زیرخط بده.

**متوسط**

1. یک «کارت» بساز: عرض ثابت، `padding`، `border`، گوشه‌ی گرد، وسط‌چین با `margin: auto`.
2. با `::before` یک نشان «جدید» به کارت اضافه کن.
3. دو پس‌زمینه‌ی گرادیان متفاوت برای دو بخش صفحه بساز.

**چالشی**

1. بدون فریم‌ورک، یک «نوار ناوبری» افقی با `inline-block` بساز (با `hover` و وضعیت `active`) و بعد از یادگیری Flexbox همین را دوباره بساز و تفاوت را ببین.

### آیا CSS مقدماتی را بلدم؟

**سؤالات مفهومی**

1. چرا `box-sizing: border-box` تقریباً همیشه تنظیم می‌شود؟
2. فرق `rem` و `em` چیست و برای فونت بدنه کدام بهتر است؟
3. چرا `a:hover` یک Pseudo-class و `a::after` یک Pseudo-element است؟
4. چرا نباید `id` را برای استایل‌دهی زیاد به‌کار برد؟
5. چرا `line-height: 1.8` از `line-height: 28px` بهتر است؟
6. فرق `display: none` و `visibility: hidden` و `opacity: 0` چیست؟

**تمرین کوتاه (کد را بخوان)**

7. عرض واقعی این المان روی صفحه چقدر است؟ و اگر `box-sizing: border-box` بود چقدر می‌شد؟

```css
.box {
  width: 200px;
  padding: 20px;
  border: 5px solid black;
}
```

8. کدام المان‌ها با این selectorها انتخاب می‌شوند؟

```css
ul li { }
ul > li { }
h2 + p { }
h2 ~ p { }
```

HTML برای این:

```html
<ul>
  <li>A
    <ul><li>B</li></ul>
  </li>
</ul>
<h2>عنوان</h2>
<p>۱</p>
<p>۲</p>
```

9. چرا این استایل کاری نمی‌کند؟ (دو دلیل)

```css
span { width: 200px; margin-top: 30px; }
.badge::before { color: red; }
```

### پروژه‌ی سطح CSS مقدماتی: «استایل‌دهی صفحه‌ی معرفی شخصی»

- **هدف:** استایل‌دهی پروژه‌ی «صفحه‌ی معرفی شخصی» فصل ۲ و ساخت یک ظاهر یکپارچه.
- **امکانات:** فونت و رنگ‌های هماهنگ، ناوبری افقی (با `inline-block`)، Hero با پس‌زمینه‌ی گرادیان یا تصویر، کارت‌های علاقه‌مندی‌ها، حالت `hover` و `focus` برای لینک‌ها، یک فوتر.
- **مهارت‌ها:** رنگ، واحد، Box Model، Selector، Background، فونت، `display`.
- **محدودیت‌ها:** فقط یک فایل CSS خارجی؛ بدون Flexbox/Grid؛ بدون `inline style`؛ همه‌ی اندازه‌های فونت و فاصله با `rem`؛ بدون فریم‌ورک.
- **معیار قبولی:**
  - نسبت کنتراست همه‌ی متن‌ها حداقل ۴.۵ به ۱ (با DevTools بسنج).
  - `box-sizing: border-box` سراسری.
  - حالت `:hover` و `:focus-visible` برای لینک‌ها مشخص و واضح.
  - هیچ `id` برای استایل استفاده نشده است.
  - صفحه را با زوم مرورگر ۲۰۰٪ بخوان و چیزی از هم نپاشد.

### پاسخنامه‌ی مختصر (پس از تلاش خودت ببین)

**سؤال ۷:** عرض واقعی `250px` است (۲۰۰ + ۲×۲۰ + ۲×۵). با `border-box` همان `200px`.

**سؤال ۸:** `ul li` هر دو (`A` و `B`) را می‌گیرد. `ul > li` هم هر دو را می‌گیرد، چون هر کدام فرزند مستقیم یک `ul` است (تفاوت وقتی دیده می‌شود که `li` در عمق بیشتری باشد، مثلاً داخل یک `div` درون `ul`؛ آن‌وقت فقط `ul li` آن را می‌گیرد). `h2 + p` فقط پاراگراف «۱» را می‌گیرد و `h2 ~ p` هر دو پاراگراف را.

**سؤال ۹:** `span` المان `inline` است و `width` و `margin-top` عمودی روی آن اثر ندارند؛ `::before` بدون `content` ساخته نمی‌شود.
