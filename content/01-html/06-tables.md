---
title: جدول‌ها
---

جدول برای نمایش **داده‌های جدولی** است (مثل لیست قیمت یا نمرات). هرگز برای چیدمان صفحه از آن استفاده نکنید؛ چیدمان کار CSS (Flexbox و Grid) است.

## ساختار پایه

```html
<table>
  <caption>نمرات دانش‌آموزان</caption>
  <thead>
    <tr>
      <th scope="col">نام</th>
      <th scope="col">ریاضی</th>
      <th scope="col">علوم</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>سارا</td>
      <td>۱۸</td>
      <td>۲۰</td>
    </tr>
    <tr>
      <td>علی</td>
      <td>۱۶</td>
      <td>۱۷</td>
    </tr>
  </tbody>
</table>
```

| تگ | معنی |
|---|---|
| `<table>` | کل جدول |
| `<caption>` | عنوان جدول |
| `<thead>` `<tbody>` `<tfoot>` | سرجدول، بدنه و پاجدول |
| `<tr>` | یک ردیف (Table Row) |
| `<th>` | سلول عنوان (پررنگ و وسط‌چین به‌صورت پیش‌فرض) |
| `<td>` | سلول داده |

ویژگی `scope="col"` یا `scope="row"` به صفحه‌خوان‌ها می‌گوید `<th>` عنوان ستون است یا ردیف.

## ادغام سلول‌ها

```html
<tr>
  <td colspan="2">این سلول دو ستون را می‌گیرد</td>
</tr>
<tr>
  <td rowspan="2">این سلول دو ردیف را می‌گیرد</td>
  <td>الف</td>
</tr>
<tr>
  <td>ب</td>
</tr>
```

## ظاهر جدول

جدول به‌صورت پیش‌فرض خط و فاصله ندارد. با CSS:

```css
table { border-collapse: collapse; width: 100%; }
th, td { border: 1px solid #ccc; padding: 8px; text-align: right; }
th { background: #f0f0f0; }
```

`border-collapse: collapse` مرز سلول‌های مجاور را یکی می‌کند.

## اشتباهات رایج

- قراردادن `<td>` خارج از `<tr>`.
- نوشتن تعداد سلول‌های نابرابر در ردیف‌ها (جدول به‌هم می‌ریزد).
- استفاده از `<th>` برای بزرگ‌کردن متن به‌جای عنوان واقعی.
- ساخت چیدمان صفحه با جدول.

> 💡 **تمرین:** جدول برنامه‌ی هفتگی کلاس‌هایتان را بسازید (ستون‌ها روزها، ردیف‌ها ساعت‌ها) و یک سلول را با `colspan` ادغام کنید.
