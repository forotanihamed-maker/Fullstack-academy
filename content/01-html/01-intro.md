---
title: HTML چیست و از کجا شروع کنیم؟
---

**HTML** مخفف HyperText Markup Language است و «زبان نشانه‌گذاری» نام دارد، نه زبان برنامه‌نویسی. یعنی محاسبه و تصمیم‌گیری ندارد؛ فقط به مرورگر می‌گوید هر تکه از محتوا **چیست**: عنوان، پاراگراف، لینک، تصویر، جدول و...

یک مثال ساده برای فهمیدن سه زبان اصلی وب: اگر صفحه‌ی وب یک ساختمان باشد، **HTML** اسکلت و دیوارها، **CSS** رنگ و نما و دکوراسیون، و **JavaScript** برق و آسانسور و درهای خودکار است.

## چه چیزی لازم دارید؟

هیچ هزینه‌ای لازم نیست. فقط این دو چیز:

1. یک **ویرایشگر کد**. پیشنهاد: [VS Code](https://code.visualstudio.com/) که رایگان است. افزونه‌ی **Live Server** را هم نصب کنید تا با هر ذخیره، صفحه خودکار در مرورگر به‌روز شود.
2. یک **مرورگر** (Chrome، Firefox یا Edge).

## اولین صفحه‌ی شما

1. یک پوشه به نام `my-site` بسازید و در VS Code باز کنید.
2. فایلی به نام `index.html` بسازید.
3. این کد را بنویسید و ذخیره کنید (`Ctrl+S`):

```html
<!DOCTYPE html>
<html lang="fa" dir="rtl">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>اولین صفحه‌ی من</title>
  </head>
  <body>
    <h1>سلام دنیا!</h1>
    <p>این اولین صفحه‌ی وب من است.</p>
  </body>
</html>
```

4. روی فایل راست‌کلیک و **Open with Live Server** را بزنید.

## هر خط یعنی چه؟

| خط | معنی |
|---|---|
| `<!DOCTYPE html>` | به مرورگر می‌گوید این سند HTML5 است |
| `<html lang="fa" dir="rtl">` | ریشه‌ی سند؛ زبان فارسی و جهت راست‌به‌چپ |
| `<head>` | اطلاعات «درباره‌ی» صفحه که نمایش داده نمی‌شود |
| `<meta charset="UTF-8">` | کدگذاری حروف؛ بدون آن حروف فارسی خراب نمایش داده می‌شود |
| `<meta name="viewport" ...>` | نمایش درست در موبایل |
| `<title>` | عنوان تب مرورگر |
| `<body>` | هرچه کاربر می‌بیند اینجاست |

## اشتباهات رایج مبتدی‌ها

- **فراموش کردن `charset`**: حروف فارسی به شکل علامت‌های عجیب دیده می‌شوند.
- **ذخیره نکردن فایل** قبل از رفرش مرورگر.
- **پسوند اشتباه**: در ویندوز ممکن است فایل `index.html.txt` ساخته شود. در File Explorer گزینه‌ی نمایش پسوند فایل‌ها را روشن کنید.

> 💡 **تمرین:** صفحه‌ای بسازید که اسم شما را در عنوان و یک جمله درباره‌ی خودتان را در پاراگراف نشان دهد. عنوان تب را هم تغییر دهید.
