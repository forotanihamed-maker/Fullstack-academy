## دسترس‌پذیری (Accessibility یا a11y)

یعنی سایت برای **همه** قابل استفاده باشد: نابینایان، کسانی که فقط با کیبورد کار می‌کنند، افراد کم‌بینا، ناشنوایان و حتی کسی که زیر نور شدید آفتاب با موبایل سایت را می‌بیند. دسترس‌پذیری یک «امکان اضافه» نیست؛ کیفیت پایه‌ی هر سایت است.

### چک‌لیست پایه‌ی HTML

| مورد | چطور |
|---|---|
| ساختار | از تگ‌های معنایی (`header`، `main`، `nav`) و سلسله‌مراتب درست عنوان‌ها استفاده کنید |
| تصویر | `alt` معنادار؛ برای تصویر تزئینی `alt=""` |
| فرم | هر فیلد `label` جفت‌شده با `for`/`id` داشته باشد |
| لینک‌ها | متن لینک معنادار («دانلود راهنما» نه «اینجا») |
| زبان | `lang` روی تگ `html` |
| کیبورد | همه چیز باید با `Tab` و `Enter` قابل استفاده باشد؛ از `<button>` برای دکمه استفاده کنید، نه `<div>` |
| رنگ | کنتراست کافی بین متن و پس‌زمینه؛ اطلاعات را فقط با رنگ منتقل نکنید |

### ARIA

وقتی تگ معنایی کافی نیست، ویژگی‌های ARIA معنا اضافه می‌کنند:

```html
<button aria-label="بستن پنجره">✕</button>
<nav aria-label="منوی اصلی">...</nav>
```

قانون طلایی ARIA: **اول از تگ معنایی استفاده کنید.** `<button>` بهتر از `<div role="button">` است.

### تست ساده

سایت خودتان را فقط با کیبورد (`Tab`) پیمایش کنید. اگر نتوانستید به همه‌ی دکمه‌ها و لینک‌ها برسید یا نفهمیدید فوکوس کجاست، مشکل دارید.

## مبانی SEO

SEO یعنی کمک به موتورهای جستجو برای فهمیدن و نمایش صفحه‌ی شما. بخش مهمی از آن همین HTML درست است:

```html
<head>
  <title>آموزش HTML از صفر | آکادمی</title>
  <meta name="description" content="آموزش رایگان HTML به زبان ساده، با تمرین و مثال.">
  <link rel="canonical" href="https://example.com/html">
</head>
```

- **title** یکتا و توصیفی برای هر صفحه (حدود ۶۰ حرف).
- **description** خلاصه‌ی جذاب (حدود ۱۶۰ حرف)؛ در نتایج جستجو دیده می‌شود.
- یک `h1` و عنوان‌های مرتب.
- `alt` برای تصویرها و **لینک‌های توصیفی**.
- آدرس‌های خوانا (`/html/forms` بهتر از `/p?id=83`).
- سرعت و سازگاری با موبایل (`meta viewport`).

> 💡 **تمرین:** صفحه‌ی خودتان را با ابزار **Lighthouse** در DevTools کروم (تب Lighthouse) بسنجید و بخش Accessibility و SEO را ببینید. مواردی که امتیاز را پایین آورده‌اند را اصلاح کنید.
