## عنوان‌ها (Headings)

شش سطح عنوان داریم، از `<h1>` (مهم‌ترین) تا `<h6>`:

```html
<h1>عنوان اصلی صفحه</h1>
<h2>بخش اول</h2>
<h3>زیربخش</h3>
```

قاعده‌ها: در هر صفحه معمولاً **یک** `<h1>` بگذارید؛ سطح‌ها را **بدون پرش** بنویسید (بعد از h2 مستقیم h4 نیاید)؛ و از عنوان فقط برای ساختار استفاده کنید، نه برای بزرگ‌کردن متن. موتورهای جستجو و کاربران نابینا با عنوان‌ها در صفحه حرکت می‌کنند.

## پاراگراف و شکستن خط

```html
<p>این یک پاراگراف است. فاصله‌های اضافه و Enterهای پشت‌سرهم
در HTML به یک فاصله تبدیل می‌شوند.</p>

<p>خط اول<br>خط دوم داخل همان پاراگراف</p>
<hr> <!-- خط جداکننده -->
```

> ⚠️ برای ایجاد فاصله‌ی عمودی از چند `<br>` پشت‌سرهم استفاده نکنید. فاصله‌گذاری کار CSS است.

## تأکید و متن‌های ویژه

| تگ | کاربرد |
|---|---|
| `<strong>` | اهمیت زیاد (پررنگ) |
| `<em>` | تأکید در لحن (کج) |
| `<mark>` | هایلایت |
| `<small>` | متن کوچک‌تر مثل تذکر |
| `<code>` | قطعه کد در خط |
| `<pre>` | متن با حفظ فاصله‌ها و خطوط (برای کد چندخطی) |
| `<blockquote>` | نقل‌قول بلند |

تفاوت `<strong>` با `<b>`: هر دو پررنگ‌اند ولی `<strong>` **معنا** دارد (مهم است) و `<b>` فقط ظاهر.

## لیست‌ها

```html
<!-- لیست بدون ترتیب -->
<ul>
  <li>HTML</li>
  <li>CSS</li>
</ul>

<!-- لیست مرتب -->
<ol>
  <li>نصب ویرایشگر</li>
  <li>ساخت پوشه</li>
</ol>

<!-- لیست توضیحی -->
<dl>
  <dt>HTML</dt>
  <dd>زبان ساختار صفحه</dd>
</dl>
```

لیست‌ها را می‌شود تودرتو کرد: یک `<ul>` را **داخل** یک `<li>` بگذارید (نه مستقیم داخل `<ul>` دیگر).

> 💡 **تمرین:** یک صفحه‌ی «رزومه‌ی ساده» بسازید: یک h1 (اسم)، چند h2 (مهارت‌ها، تحصیلات) و یک لیست برای مهارت‌ها.
