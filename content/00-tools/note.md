---
title: شروع کار و ابزارها
---

قبل از نوشتن کد باید با سه ابزار آشنا شوید: **ویرایشگر کد** (مثل VS Code)، **ترمینال** و **DevTools مرورگر**.

## ترمینال

ترمینال محیطی متنی برای دادن دستور به کامپیوتر است. چند دستور پایه:

```bash
pwd          # نمایش مسیر فعلی
ls           # نمایش فایل‌های پوشه (در ویندوز CMD: dir)
cd projects  # ورود به پوشه
mkdir app    # ساخت پوشه
cd ..        # یک پوشه بالاتر
```

## DevTools مرورگر

با کلید `F12` باز می‌شود:

| تب | کاربرد |
|---|---|
| Elements | دیدن و تغییر ساختار HTML و CSS صفحه |
| Console | خطاها و خروجی `console.log` |
| Network | درخواست‌هایی که صفحه به سرور می‌فرستد |

مطالعه بیشتر: [مستندات VS Code](https://code.visualstudio.com/docs)
