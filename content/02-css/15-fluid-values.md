## `calc()`
برای ترکیب واحدها و ساخت مقدار محاسبه‌شده استفاده می‌شود:

```css
.container {
  width: calc(100% - 2rem);
}
```

## `min()` و `max()`
برای تعیین سقف یا کف مقدار مناسب‌اند:

```css
.container {
  width: min(100% - 2rem, 1100px);
}
```

## `clamp()`
سه مقدار دارد: حداقل، مقدار ترجیحی و حداکثر:

```css
h1 {
  font-size: clamp(1.75rem, 1.2rem + 2.5vw, 3rem);
}
```

مقدار ترجیحی فقط `vw` نباشد؛ ترکیب `vw` و `rem` کمک می‌کند zoom مرورگر بهتر عمل کند.

### تمرین مفهومی
یک container بسازید که همیشه حداقل 16px از دو طرف فاصله داشته باشد و از 1100px پهن‌تر نشود.

## تصمیم‌گیری بین px، rem، درصد و clamp

واحد را بر اساس چیزی که می‌خواهید کنترل کنید انتخاب کنید:

- `px`: برای جزئیات بسیار مشخص یا مرزهایی که نیاز به اندازه‌ی ثابت دارند.
- `rem`: برای typography و spacingهایی که باید با تنظیمات root/zoom کاربر هماهنگ بمانند.
- `%`: برای رابطه با اندازه‌ی containing block.
- `vw`/`vh`: برای رابطه با viewport، با احتیاط در موبایل.
- `clamp()`: وقتی مقدار باید حداقل، مقدار ترجیحی و حداکثر داشته باشد.

## الگوی clamp

```css
h1 {
  font-size: clamp(1.75rem, 1rem + 3vw, 3rem);
}
```

به زبان ساده: مقدار از `1.75rem` کوچک‌تر نمی‌شود، تمایل دارد با `1rem + 3vw` رشد کند و از `3rem` بیشتر نمی‌شود.

## calc برای ترکیب مقیاس‌ها

```css
.container {
  width: min(100% - 2rem, 70rem);
}
```

`calc()` زمانی ارزشمند است که دو نوع اندازه را باید در یک رابطه قرار دهید؛ `min()` و `max()` برای انتخاب محدودشده و `clamp()` برای یک بازه‌ی سه‌نقطه‌ای مناسب‌اند.

## خطای رایج

همه‌ی چیز را با `vw` نسازید. اگر فونت بدون سقف رشد کند، در نمایشگر بزرگ خوانایی خراب می‌شود؛ اگر فاصله‌ها فقط با px ثابت باشند، در حالت‌های مختلف ممکن است خشک شوند. هدف، **ترکیب آگاهانه‌ی واحدها** است.

### تمرین دیباگ

یک heading با `clamp()` بسازید و در 320، 768 و 1440 پیکسل مقدار Computed را ثبت کنید. سپس min و max را تغییر دهید و توضیح دهید کدام بازه واقعاً تغییر می‌کند.
