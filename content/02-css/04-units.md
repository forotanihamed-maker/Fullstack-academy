## چرا واحد مهم است؟

اگر همه اندازه‌ها را با مقدار ثابت بنویسیم، رابط در اندازه‌های مختلف صفحه و تنظیمات متفاوت کاربر انعطاف کمتری خواهد داشت. واحد مناسب به responsive و accessibility کمک می‌کند.

| واحد | کاربرد رایج |
|---|---|
| `px` | border و جزئیات کوچک |
| `%` | اندازه نسبت به والد، مثل `width: 50%` |
| `rem` | اندازه نسبت به فونت ریشه، مناسب فونت و فاصله |
| `em` | اندازه نسبت به فونت همان عنصر یا زمینه وراثتی |
| `vw` / `vh` | درصدی از viewport |
| `ch` | محدود کردن عرض متن بر اساس عرض کاراکتر |

## rem

اگر اندازه فونت ریشه معمولاً ۱۶px باشد:

```css
h1 {
  font-size: 2.5rem;
}

p {
  max-width: 65ch;
}
```

در این مسیر برای فونت و فاصله‌ها ترجیح می‌دهیم از `rem` استفاده کنیم تا تغییر اندازه فونت مرورگر بهتر در رابط اثر بگذارد.

## em

`em` به اندازه فونت زمینه وابسته است:

```css
button {
  padding: 0.75em 1.5em;
}
```

این ویژگی می‌تواند برای اجزایی که باید همراه اندازه فونت خودشان مقیاس شوند مفید باشد، اما تو در تو شدن `em`ها ممکن است اندازه‌ها را ناخواسته چند برابر کند.

## Viewport units

```css
.hero {
  min-height: 100vh;
}
```

در موبایل، `vh` ممکن است با نوار مرورگر رفتار ایده‌آلی نداشته باشد. واحدهای مدرن `dvh` و `svh` برای سناریوهای viewport پویا مفیدند.

## نکات عملی

- فونت: معمولاً `rem` بهتر از `px` است.
- فاصله: `rem` یا در بعضی اجزا `em`.
- جزئیات ریز مثل border: `px`.
- عرض‌های انعطاف‌پذیر: `%`، `fr` و `max-width` در مباحث layout.
- `width: 100vw` ممکن است به‌دلیل scrollbar اسکرول افقی ایجاد کند؛ برای بسیاری از کانتینرها `width: 100%` مناسب‌تر است.

## تمرین

اندازه فونت ریشه را `100%` قرار دهید، اندازه‌های یک صفحه را به `rem` منتقل کنید و سپس اندازه فونت مرورگر را افزایش دهید و رفتار صفحه را مشاهده کنید.

## تفاوت «مرجع اندازه‌گیری» واحدها

مهم‌ترین سؤال هنگام انتخاب واحد این نیست که «کدام واحد بهتر است؟» بلکه این است که **این اندازه باید نسبت به چه چیزی تغییر کند؟**

- `px`: مقدار تقریباً ثابت در CSS layout؛ مناسب border و جزئیات کنترل‌شده.
- `%`: معمولاً نسبت به اندازه‌ی containing block همان property.
- `rem`: نسبت به font-size ریشه.
- `em`: در بسیاری از propertyها نسبت به font-size خود عنصر محاسبه می‌شود؛ بنابراین تو در تو شدن آن می‌تواند اثر زنجیره‌ای بسازد.
- `vw`/`vh`: نسبت به viewport.
- `dvh`/`svh`: برای رفتارهای متفاوت viewport موبایل.
- `ch`: یک واحد وابسته به اندازه‌ی کاراکتر `0` در فونت جاری و برای کنترل تقریبی عرض متن مفید است.

## یک دام مهم درباره em

```css
.parent { font-size: 1.25em; }
.child { font-size: 1.2em; }
```

اگر چند سطح تو در تو داشته باشید، مقدار `em` می‌تواند مرحله‌به‌مرحله تغییر کند. برای سیستم typography سراسری معمولاً `rem` قابل پیش‌بینی‌تر است؛ `em` را جایی به کار ببرید که واقعاً می‌خواهید جزء همراه font-size خودش مقیاس شود.

## ترکیب واحدها با calc

واحدها همیشه رقیب هم نیستند و می‌توانند ترکیب شوند:

```css
.container {
  width: min(100% - 2rem, 70rem);
}

.hero-title {
  font-size: clamp(1.75rem, 1rem + 3vw, 3rem);
}
```

`calc()` برای ترکیب مقدارهای مختلف مفید است و `min()`/`max()`/`clamp()` بعداً ابزار اصلی ساخت اندازه‌های سیال می‌شوند.

## چرا 100vw گاهی اسکرول افقی می‌سازد؟

`vw` عرض viewport را در نظر می‌گیرد و بسته به محیط ممکن است فضای scrollbar را نیز در محاسبه وارد کند. برای یک عنصر معمولی که باید عرض والد را پر کند، `width: 100%` اغلب انتخاب طبیعی‌تری است.

## واحد برای Typography، Spacing و Layout

یک تصمیم عملی می‌تواند چنین باشد:

| نیاز | انتخاب شروع مناسب | دلیل |
|---|---|---|
| ضخامت border | `px` | کنترل دقیق |
| متن اصلی | `rem` | مقیاس‌پذیری |
| فاصله‌های سیستم طراحی | `rem` | هماهنگی |
| عرض متن | `%`/`ch`/`max-width` | وابستگی به محتوا |
| Hero تمام‌صفحه | `dvh`/`svh` با توجه به سناریو | viewport موبایل |

این‌ها قانون مطلق نیستند؛ رفتار مورد انتظار را اول مشخص کنید.

## آزمایش DevTools

یک صفحه را با سه حالت تست کنید: عرض 320px، عرض دسکتاپ و افزایش اندازه فونت مرورگر. اگر layout فقط در حالت پیش‌فرض خوب است، واحدها و محدودیت‌های عرض را دوباره بررسی کنید.

### تمرین دیباگ

```css
.card { width: 100vw; padding: 2rem; }
.title { font-size: 2em; }
```

دو مشکل احتمالی را پیدا کنید: یکی مربوط به عرض viewport و دیگری مربوط به مقیاس typography. سپس نسخه‌ی قابل پیش‌بینی‌تری بنویسید.

## معیار تسلط

باید بتوانید برای یک مقدار مشخص توضیح دهید «نسبت به چه چیزی» اندازه‌گیری می‌شود و چرا `rem`، `em`، `%`، `vw` یا `dvh` را انتخاب کرده‌اید.
